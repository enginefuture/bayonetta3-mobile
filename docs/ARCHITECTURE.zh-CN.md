# 当前实现分析

[English](ARCHITECTURE.md) · [首页](../README.zh-CN.md)

当前实现由固定版本的离线程序改写器、原生 Horizon 服务适配及 NVN → Metal 图形后端组成。游戏逻辑来自用户自己的原始程序；运行链中没有串流服务或模拟器应用启动器。

| 层次 | 实现 | 当前判断 |
|---|---|---|
| 本地准备 | `tools/prepare.py` 检查 PFS0 范围，按 Program ID 选择内容，用本地 NSTool 合并本体/更新 | 生成私有 ExeFS/RomFS，不下载游戏 |
| 程序改写 | `tools/rewrite.py` 先核对 Build ID/SHA-256，再调用上游 `patch_nso.py` | 适配系统调用、线程寄存器、计时器和 Apple ABI 冲突；加载 `main/subsdk0/sdk` |
| 验证 | LLVM 结构检查、Unicorn 随机等价和变异负对照 | 属于必要检查，不证明并发语义；测试会替换两侧独占访存 |
| 原生宿主 | 通用加载器、内存/线程/文件/输入/音频/影片服务及 `hle_bayonetta3.c` | 适配已观察的 SDK 调用，未实现调用明确失败 |
| NVN 55.12 | ABI 包装、纹理/视图、描述符、延迟状态与命令提交 | 是本目标所需的接口子集，不是完整 NVN 驱动 |
| 着色器 | 本地采集 → Ryujinx 翻译库 → SPIR-V → SPIRV-Cross MSL → Metal 编译器 | 离线翻译，代码和缓存均保持私有 |
| macOS | Cocoa 窗口、CAMetalLayer、键盘/手柄映射及独立存档 | 开场与基础操作已观察，未验收完整游戏 |
| iOS | UIKit 外壳、内嵌改写模块、Metal 库与虚拟手柄 | 未签名构建通过，未验证签名安装和真机行为 |

## 本游戏需要的关键改动

继承的驱动采用较早的 NVN ABI。本目标需要 128 字节纹理对象、16 字节视图、多种 GPU 控制段长度、正确的描述符命名空间，以及提交时冻结延迟绑定。还实现了间接计算、GPU 计数间接绘制、alpha 比较、已有深度范围测试、swizzle/mip 区域和无附件片元通道；后者恢复曝光缓冲写入，是实际 3D 从黑屏中恢复的关键。

后台管线预测曾把未来着色器绑定和裁剪状态泄漏到当前绘制。现在阶段绑定随绘制状态保存/恢复，预测后还原 raster 状态；阶段组合查找从线性扫描改为规范化完整身份哈希键。冻结的阶段配对快照参与翻译链指纹，避免新接口错误复用旧缓存。

影片服务按实测 ABI 适配。测试中的 AVFoundation 路径无法直接解码该 VP9 原片，因此由用户生成私有 AVC 缓存，宿主实际解码帧并保留原始时间轴；AVC 为有损转换，不宣称画质等价。

## 当前证据能支持什么

Mac 实测支持标题交互、开场实时渲染以及基础移动/动作反馈。部分 Metal HUD 开场区间接近 60 FPS、GPU 中位耗时约 11–12 ms，同时记录了掉帧和长停顿。测试覆盖合成指令改写、服务缓冲边界、NVN 布局/延迟绑定、纹理区域、alpha/深度操作、间接参数准备及无附件片元写入。

这些结果不能证明完整战斗、后续章节、音频、存档往返或所有绘制路径正确。细分阶段尚不支持，材质/发丝/透明效果仍有问题。iOS 未签名编译只证明构建结果；签名、内存/地址空间、GPU、输入及生命周期必须真机验证。
