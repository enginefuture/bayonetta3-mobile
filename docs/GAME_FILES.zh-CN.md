# 游戏文件：仅使用自己的副本

[English](GAME_FILES.md) · [首页](../README.zh-CN.md)

**请购买正版 Bayonetta 3，支持创作者。本项目不提供任何游戏内容。** 仅使用自己合法拥有的副本，并遵守适用于你的使用规则。本政策说明项目接收哪些内容，不保证“拥有正版”在所有地区都意味着任何提取和使用方式均被允许。

## 本地需要准备

- 自己的 Switch 本体文件，以及与支持指纹一致的 1.2.0 更新。
- 自己在本地取得、供提取工具使用的密钥。不要向维护者发送密钥。
- 本地提取工具，例如 NSTool；开发使用 1.9.2。工具不是游戏文件来源。

教程从你已经拥有的本地文件开始，不包含第三方游戏下载站、他人密钥或账号获取教程。本移植没有游戏资源下载功能。

`tools/prepare.py` 只读取你显式传入的路径，选择主 Program ID，并将本体和更新合并到私有工作区。不会自动搜索模拟器目录、修改模拟器配置或接触模拟器存档；运行时也不依赖 Ryujinx。

## 绝不能公开上传

| 私有内容 | 包括 |
|---|---|
| 分发文件 | NSP、NSZ、XCI、XCZ、NCA、票据、证书 |
| 游戏程序 | NSO/ExeFS、解压映像、改写二进制及内嵌映像汇编 |
| 资源 | RomFS、PKZ/PAK、纹理、音频、影片及转码缓存 |
| 游戏着色器 | 原始采集、打包、SPIR-V/MSL 翻译、Metal 库及生成的逐游戏反射/缓存表 |
| 个人资料 | 密钥、凭据、签名身份、描述文件及存档 |
| 安装包 | 包含上述内容的 App、IPA 或归档 |

本地 iOS 构建会内嵌自己改写的游戏模块和着色器。**即使没有包含 RomFS，也不能把该 App/IPA 上传到 Release。** 开源许可证只涵盖兼容层源码，不涵盖这些游戏模块。

私有内容放在被忽略的 `work/`，原始 NSP/密钥也可以保留在仓库外。不要放进示例或测试夹具。同样禁止进入 Git 历史、LFS、Issue、评论、PR 附件、Release、Actions 缓存和产物。仅分享脱敏的简短错误摘要，不要打包整个运行目录或转储。

## 仓库公开什么

源码、合成测试、教程、许可证、版本指纹与有限的接口描述。接口元数据见 [DERIVED.md](DERIVED.md)，不包含原始程序字节或着色器主体。忽略规则、暂存/历史审计及 CI 辅助检查边界，仍需人工审查。

如误加入私有内容，应停止发布，从待提交内容及历史中清理，并按需轮换泄露凭据；不要在公开报告中引用或再次上传敏感内容。
